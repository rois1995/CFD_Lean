# CFD_Lean

CFD_Lean develops finite-volume methods in Lean. It connects mathematical claims about numerical schemes to executable kernels and records the evidence for each step. Start with the periodic one-dimensional Burgers and Euler schemes or follow the separate median-dual Euler/Roe line.
