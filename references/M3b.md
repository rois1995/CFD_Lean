## Construction and proof dependencies

Local.lean defines cross products, oriented triangle area, absolute determinant volume, midpoints, face centroids and cell centroid. The 24 flags are permutations (i,j,k,l); six have each first vertex. Flag determinants are frameSign times the primal determinant divided by 24. Absolute volume removes arbitrary flag ordering. The same orientation sign multiplies each flag's four face vectors. Each boundary sum vanishes. Explicit j/k and k/l involutions pair its internal faces; the remaining faces are identified with the two edge-interface triangles and the two triangles in each vertex's primal-face patch. Their sum gives local_closure. Each outward interface triangle has dot product sixVolume/24 with p_j-p_i, strictly positive on every MeshData cell. localInterface is antisymmetric, and each primal-face owner patch has one third of that face's oriented vector. Positively ordering cells loses no nondegenerate tetrahedron: swapping vertices 1/2 reverses the determinant.

Mesh.lean stores finite coordinates, injective four-node cell maps and positive primal determinants. Conforming separately requires unique cell vertex sets, coordinate injectivity on used node IDs, exact hull intersections through common node IDs, at most two computed occurrences per three-node face, and opposite plane sides at a shared face. No closure, area cancellation, volume identity or residual conclusion is an input. Face incidence is computed by erasing one vertex from each cell. face_membership proves that every three-node subset of a cell is exactly one such face. Shared-face areas have equal magnitude up to orientation by unordered triangle-node equality; the genuine opposite-side assumption chooses the negative sign. Thus faceArea_cancel is derived, not provided by the caller. Stronger algebraic helpers expose the smaller assumptions they need; the public concrete closure theorem retains Conforming. These are mathematical input assumptions, not a mesh parser or validator.

Edges.lean defines Edge as precisely the subtype of increasing node pairs co-occurring in a primal cell. This is a finite set of actual IDs with one orientation and no duplicate record per unordered primal edge. assembledArea sums localInterface over all incident cell/local-index pairs matching those endpoints; localInterface itself sums the two actual barycentric triangle vectors. edgeArea supplies that sum to the unchanged Assembly.roeTransfer. The proved antisymmetry, support and row-sum identities derive edge_incidence_sum, which identifies the canonical edge scatter with the sum of local outward interfaces. The nonlinear numerical flux is evaluated once after aggregation; no facetwise flux equivalence is assumed.

Boundary.lean defines Boundary by a computed single-incidence primal face and a node in that face, retaining its cell occurrence. ownedPatch_local identifies its area with the original local flag triangles. boundaryKey_injective and boundaryKey_range prove exactly one record for each exterior primal-face/owner pair, with neither omitted nor duplicate patches. Interior occurrences have a uniquely determined other cell face from cardinality two. partner is derived from these actual occurrences, is an involution and has no fixed point. Shared-face area cancellation then cancels every interior owner patch. all_patches_boundary identifies precisely the survivors with this same Boundary and boundaryArea.

MedianDual.lean constructs the exact Assembly.Interfaces consumed by Roe. metric_closed follows by summing the local flag closure, using the edge incidence identity and interior/exterior patch reduction. constant_state applies the accepted constant_state_closed to these exact E/B/S/T records. Supplied boundary data are the actual physicalTransfer on each concrete exterior area. roe_boundary_balance specializes the accepted global balance to this same edge-aggregated numerical flux and arbitrary supplied exterior transfers. The statements are algebraic identities on raw state records; physical specialization still requires gamma>1 and M1 admissibility. No arbitrary boundary algorithm is claimed to preserve a common state.

## Volumes and claims

localDualVolume is the sum of the six actual absolute flag determinant volumes. Each is Vol(T)/24, so it equals Vol(T)/4. dualVolume sums these contributions by incident node identity; dualVolume_formula derives exactly the specified incident Vol(T)/4 expression. dualVolume_pos requires Used, dualVolume_unused gives zero at isolated nodes, and volume_partition proves the total primal-volume identity.
