## The matrix-order discrepancy

I inspected the supplied Toro third edition, printed p. 355 (PDF p. 374). Eq. (11.57) prints B C⁻¹. The matrices on that page send a parameter increment to a state increment (B) and a flux increment (C). With column vectors, the Roe matrix must satisfy A B = C, giving **A = C B⁻¹**. For the five-component parameter vector in lines 105–122, direct differentiation gives det B = 2 z₀⁵/γ. At the midpoint z₀ is positive. C can be singular at a stationary contact. Making its inverse an assumption would remove a state that the numerical flux must handle.

LeVeque, printed p. 320, Eqs. (15.26)–(15.27), gives this same composition. Roe’s original matrix construction immediately before Eq. (17) uses it as well. The user-supplied file named roe1997.pdf is the 1997 reprint of the 1981 paper, with different pagination. Use the original citation and label reprint page references separately. Record Toro's equation as a suspected printing error. An author-confirmed erratum remains unverified. ## Independent checks and their limits

The included SymPy script differentiated the physical flux and both quadratic parameter maps independently of the proposed operator. It verified the midpoint jump identities, determinant and A B = C symbolically for an arbitrary normal. In an oblique unit frame with symbolic velocity and sound speed it verified all five eigenvector actions, the projector values and reversal. The eigenframe determinant reduced to 2c³/(γ−1). This checks a genuinely oblique orientation. The proof for every orientation remains an M2c obligation.

For the proposed counterexample, applying the left-acoustic projector directly to the conservative jump and adding the left state gave the intermediate vector (1−2/√3, 0, 0, 0, 5/2−2√3). The negative density follows immediately. The proposal’s reported 36 preparation cases were not used as independent evidence. Reproduce the review calculations with Python and SymPy by running `python check.py`. This was a specification review; no M2 theorem has yet passed the Lean kernel.
