# Frozen M3 representation precision

This companion to M3.md carries the three domain/representation clarifications in the supplied independent review, approved with Andrea's M3 plan authorization. It does not add a result or replace a geometric conclusion with an input assumption.

1. Faithful conforming embedding uses actual node identities: coordinates are injective on used nodes; tetrahedron records have no repeated vertex set; intersections of realized convex hulls equal the convex hull of common node IDs; face incidence is exactly membership in tetrahedron vertex sets. The formal definitions may prove consequences of this representation, but must not admit duplicate cells, coincident separately labeled used nodes or omitted face incidences as valid input.
2. Build the concrete interface set once from unordered used primal edges and choose its orientation. Enumerate exterior triangles or grouped owner patches with exact multiplicities, retaining external primal-face and owning-vertex identity. M3-G must construct the map to the very same generic E/B records, S_e and T_b consumed by assembly. Generic assembly assumes finite distinct-endpoint interfaces and boundary owners; it does not validate a geometric mesh.
3. V_i denotes the explicit sum of absolute primal determinant volumes divided by four over incident elements. M3-V must derive its 24-flag subdivision, positivity at used nodes and total-volume identity. No assertion that V_i is a measure of a geometric region follows merely from naming it volume. Additional prose claiming such a measure must identify the supporting subdivision/nonoverlap result.

M3a is abstract assembly: I/R/O and conditional C only. It must not label conditional closure as the concrete M3-G theorem. M3b must derive G/V and instantiate C, without receiving closure or volume-partition conclusions as input certificates. Constant-state tests with incompatible boundary data must instantiate the actual accepted flux/constant-state interface; an arbitrary-transfer cycle alone does not test that qualification. Transported reindexing covers nodes, edges and boundary pieces, not only edge ordering.
